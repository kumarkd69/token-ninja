## LinkedIn (long-form, story-first)

I built a Figma plugin to fix a problem every design system eventually runs
into: screens that quietly drift away from your tokens.

Someone duplicates a frame, tweaks a color "just this once," and six months
later your file has 40 shades of almost-the-same-blue that nobody can safely
consolidate — because nobody remembers which layers are safe to touch.

**Token Ninja** scans any frame, finds every color and text style that isn't
bound to a token, and tells you exactly what it should be — using real color
science (CIEDE2000, the same math printers and photographers rely on) instead
of naive RGB distance. So a red never gets suggested as "close enough" to a
grey just because of how a token happens to be named.

A few things I cared about getting right:
🎨 Perceptual color matching, not guesswork
🔤 Typography matching that respects size first, weight second — never a
   random font size because a style name sounded close
🧠 It learns your file — tokens you've already used teach it your
   conventions
👁 Hover any suggestion to preview it live on canvas before committing
✅ Nothing changes without your review — always one undo step away

It's free, open source, and live on Figma Community today: 🔗 [link]

If you maintain a design system — or inherited one that's drifted — I'd love
for you to try it and tell me what breaks.
