## Description (main body)

Token Ninja scans any frame for **orphan colors and text** — values that
aren't bound to a variable or style — and intelligently maps each one to the
closest matching token in your design system. Review, preview, apply.

**Why teams use it:**
- 🎨 **Perceptual color matching** — real CIEDE2000 color science, not naive
  RGB math, so a red never gets mapped to a grey just because of how a token
  is named.
- 🔤 **Size-first typography matching** — a loose "14/Semibold" snaps to the
  nearest 14px style with the closest weight, never a random size.
- 🧠 **Learns your file** — layers already bound to variables teach Token
  Ninja which token belongs in which component.
- 🙋 **Learns from you** — pick a token manually once, and it's suggested
  first for that color every time after.
- 👁 **Hover preview** — see any suggestion live on canvas before applying.
- ⚡ **Auto-scan** — optionally scans automatically when you select a frame.
- 📊 **Health report** — token coverage %, exportable as Markdown or CSV to
  share with your team.
- ✅ **Always safe** — nothing changes without review. Bulk-apply only
  touches ≥95%-confidence matches. Every apply is one undo step.

Perfect for cleaning up legacy files, auditing a design system's adoption,
or onboarding a screen built outside your token library.
